## 二、國際水晶市場觀察（The reason to do this.）

- **市場規模**：全球療癒水晶市場各估算約 **10–15 億美元／年**，且以雙位數成長；Etsy「crystals」常年是搜尋量最大的類目之一，#CrystalTok 瀏覽數十億次（捷克隕石曾因 TikTok 全球斷貨）。
- **人群**：核心TA是 18–40 歲女性，與占星、塔羅、冥想、manifestation 文化高度重疊，Exactly為Stardust 現有月相＋顯化儀式的user zone。
- **extra pay mode已被驗證**：Moonly、CHANI、Co-Star、The Pattern 證明「宇宙能量」類 App 訂閱制成立（月費 US$4–12）；水晶實體客單價高（台灣手鍊常見 NT$800–10,000，晶洞上萬），**使用者對「圍繞水晶的數位服務」價格敏感度低**。
- **痛點（機會）**：
  1. 買了水晶記不住功效與禁忌（怕水怕曬誰記得住）→ 知識庫＋收藏綁定。
  2. 收藏散落無紀錄，遺失單據、忘記價格產地 → 收藏資料庫（同時是「資產帳本」）。
  3. 不知道何時消磁充能、不知道哪些水晶改用哪種方式淨化 → 月相引擎天然解決。
  4. 想學水晶輔助許願儀式但資訊零碎、英文為主 → 繁中在地化教學是空缺。

## 三、功能 Brainstorm（依付費意願排序）

### A 級：最可能額外訂閱（核心 / 單購）

1. **🤖 AI 水晶辨識**（拍照→自動判斷是哪種水晶）：收藏流程的 wow moment；用既有 `api/ai-chat.js` 的 Anthropic vision 即可實作，「辨識 N 次／月」是天然的訂閱閘門。
2. **🖼 個人 Minéralogie 海報輸出**：把收藏架排版成高解析度復古海報（PNG／PDF），可分享 IG 或 **print-on-demand 印成實體海報寄到家**——數位免費、實體收費，全球水晶圈沒人在做這個。
3. **🔔 消磁充能提醒訂閱**：滿月前推播「今晚適合幫這 3 顆充能（你的黑曜石已 45 天沒淨化）」；per-crystal 的保養排程是收藏庫的自然延伸。
4. **🌑 新月／滿月儀式包**：每逢新滿月推出當期主題儀式（星座月＋建議水晶＋引導音頻＋日記模板），訂閱者解鎖全部，等於 Moonly 模式＋水晶差異化。
5. **💎 命定水晶報告**（與 ÆTHNOUS 紫微／占星整合）：以生辰推薦「本命水晶、流年水晶、補運水晶」，一次性付費報告（NT$199–499），與現有命理服務交叉導流。

### B 級：留存與黏著（讓訂閱不退訂）

6. **📚 水晶學院**：圖鑑延伸的系統課程（脈輪學、消磁全指南、真假鑑別、水晶陣幾何學），完課發徽章；「真假鑑別」單元在市場上尤其剛需。
7. **🏆 收藏成就系統**：集滿七脈輪、集滿石英家族、第一顆星際隕石或特殊水晶徽章，沿用現有 streak 機制；「圖鑑收集率 37%」是強力回訪hook（寶可夢圖鑑效應）。
8. **📿 意圖追蹤**：收藏時寫下的「給它的任務」定期回訪——「你的黃水晶來到你手中 3 個月了，當時設下的財務目標有進展嗎？」串接 CBT／日記模組。
9. **🧿 水晶陣設計器**：拖拉排列自己的水晶做虛擬 grid，選神聖幾何底圖，存檔＋分享。
10. **😴 水晶 × 夢境交叉洞察**：枕邊放月光石／紫晶的日子，夢境記錄率、情緒分數有無差異——Stardust 獨有的資料交叉，別人抄不走。

### C 級：社群與商務（放大盤子）

11. **🌍 收藏牆分享頁**：一鍵生成公開網址／分享圖（復古海報風），水晶圈曬收藏文化極強，是最便宜的獲客管道。
12. **🛍 嚴選聯盟商店**：依使用者許願主題推薦可信賣家（聯盟分潤或自營選品盒「本月新月儀式盒」訂閱）。
13. **💱 收藏估值**:接市場行情給收藏總值走勢（「你的收藏市值約 NT$42,000」），高階收藏家的保險／傳承紀錄需求。
14. **🎁 送禮指南**：輸入對象與需求→推薦水晶＋祝福卡文案（禮物是水晶市場最大單筆消費場景）。
15. **🗺 水晶地圖**:收藏地點聚合成個人「水晶旅行地圖」；眾包全球水晶店家評價。
